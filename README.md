# aloSIM Redeem Helper

أداة ويب لإدارة كودات aloSIM + لوجين + إيميل مؤقت من mail.tm

## رفع على Railway

1. اعمل حساب على [railway.app](https://railway.app)
2. اضغط **New Project** → **Deploy from GitHub** أو **Empty Project**
3. ارفع الملفات دي (index.html + server.js + package.json)
4. Railway هتكتشف Node تلقائي وتشغله
5. اضغط على الـ domain اللي هتطلعه وافتحه

أو استخدم Railway CLI:

```bash
npm i -g @railway/cli
railway login
railway init
railway up
```
